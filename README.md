# HideMMR

A World of Warcraft addon that hides PvP rating numbers so you can focus on playing, not on the numbers.

## What it hides

- **PvP tab (Rated):** current rating and rank for Solo Shuffle, 2v2 and 3v3
- **Scoreboard and match results:** average MMR text
- **Score table:** MMR, rating, new rating and rating change columns
- **Match results:** the "+N rating" block with the tier icon and the MMR tooltip

## Installation

- **CurseForge:** install from the CurseForge app.
- **Manual:** download the latest release zip from [Releases](../../releases) and extract it into
  `World of Warcraft/_retail_/Interface/AddOns/`, so the result is `AddOns/HideMMR/HideMMR.toc`.

No settings: enable the addon and the numbers are gone.

# HideMMR (RU)

Аддон для World of Warcraft, который скрывает PvP-рейтинг, чтобы цифры не влияли на менталку.

## Что скрывается

- **Вкладка PvP (Рейтинговые):** текущий рейтинг и ранг в Solo Shuffle, 2v2 и 3v3
- **Таблица во время матча и итоги:** средний MMR
- **Таблица результатов:** колонки MMR, рейтинга, нового рейтинга и изменения рейтинга
- **Итоги матча:** блок «+N к рейтингу» с иконкой ранга и подсказкой с MMR

## Установка

- **CurseForge:** установить через приложение CurseForge.
- **Вручную:** скачать zip последнего релиза из [Releases](../../releases) и распаковать в
  `World of Warcraft/_retail_/Interface/AddOns/`, чтобы получилось `AddOns/HideMMR/HideMMR.toc`.

Настроек нет: включил аддон, и цифр больше не видно.
